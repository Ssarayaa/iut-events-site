**Le projet :**

- Réalisation d'un site dynamique pour le suivi des différents événements du
département (NDI, JPO, séminaires, sorties, ...) il faut qu’on puisse retrouver tous les
événements à venir au sein du département.
- Création de l'application mobile correspondante. (bonus)
- Données statistiques sur les participations pendant ces événements.

**Compétences en cours OU à acquérir :**
- Développement Web Full-Stack
- Développement Mobile
- Analyse et visualisation de données
- Gestion de projet et autonomie

**Technologie que je vais utilisées :**
- Front End : React.JS → Visual Studio Code
- Back-End : Spring Boot → IntelliJ IDEA
- Base de Donnée → MySQL
